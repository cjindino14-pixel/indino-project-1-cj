# Indino Project 1 — Personal Portfolio

## Folder structure
- `index.html` — main portfolio page
- `styles/style.css` — website styles
- `assets/profile-placeholder.svg` — replace this with your own profile picture

## Run the website
1. Extract the ZIP file.
2. Open the `indino-project-1` folder in Visual Studio Code.
3. Open `index.html` in a browser (or use the Live Server extension).
4. Replace the sample email address and project descriptions with your own details.
5. To use your own photo, copy it into `assets/`, rename it to `profile.jpg`, and update the image path in `index.html` to `assets/profile.jpg`.

## GitHub
Create a new GitHub repository named `indino-project-1`, then follow the 10-commit guide provided with the assignment instructions.
